# Agentic AI

Agent orchestration and agent architecture labs.

## Belongs here
Labs whose main purpose is agent design: graphs, tools, planning, human approval.

## Does not belong here
Operations agents (infrastructure-ai), MCP server code (mcp-a2a), complete business solutions (see _e2e-candidates).

## Labs
* uc1-sap-procurement: LangGraph purchase order flow with BPA trigger and S/4HANA release
* customer-churn-agent: predict, explain, and recommend retention actions

Technologies: LangGraph, GenAI Hub, S/4HANA OData, SAP Build Process Automation.
