# Infrastructure AI

AI assisted SAP infrastructure and operations, even when the labs use agents or RAG internally.

## Belongs here
Basis automation, system health, patching, diagnostics, and operational intelligence.

## Does not belong here
Generic agent or RAG teaching labs (rag, agentic-ai).

## Labs
* basis-copilot: Google ADK and Gemini agent for SAP Basis operations
* basis-help-assistant: LangGraph job failure agent
* patching_agent_v2: kernel patching orchestrator
* sap-diagnostic-agent: read only ECC and Oracle diagnostics
* btp-ops-intelligence: CAP dashboard for BTP landscape monitoring

Technologies: Google ADK, Gemini, LangGraph, sapcontrol, OData, CAP.
