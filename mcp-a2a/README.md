# MCP and A2A

Model Context Protocol servers and agent to agent interoperability.

## Belongs here
Labs whose main purpose is exposing SAP systems as tools or connecting agents through protocols.

## Does not belong here
Full solutions that merely use MCP (see _e2e-candidates).

## Labs
* kyma-mcp-server: S/4HANA purchase orders on Kyma
* sap-cashflow-mcp-server: cashflow data tools
* sap-procurement-mcp-server: tool layer for Joule agents

Technologies: MCP, Kyma, HANA Cloud, Joule.
